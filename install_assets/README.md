# ox_inventory item images (w2f-graverobbery)

Add **PNG** icons for the dig tool and every loot key referenced in `config.lua → Config.Loot` plus `Config.RequiredItem`. Names must match ox item keys: **`{item}.png`**.

## Where to install

Copy into:

`resources/[ox]/ox_inventory/web/images/`

Restart `ox_inventory` after adding images.

## Required files

| Image file | Item key |
|------------|----------|
| `shovel.png` | `shovel` (required tool) |
| `bone.png` | `bone` |
| `dirt.png` | `dirt` |
| `old_ring.png` | `old_ring` |
| `silver_coin.png` | `silver_coin` |
| `ruby.png` | `ruby` |
| `emerald.png` | `emerald` |
| `diamond.png` | `diamond` |
| `old_weapon.png` | `old_weapon` |
| `gold_necklace.png` | `gold_necklace` |
| `ancient_artifact.png` | `ancient_artifact` |
| `cursed_skull.png` | `cursed_skull` |
| `treasure_map.png` | `treasure_map` |

NUI artwork under `nui/digging/svg/` is separate (minigame); these PNGs are for the **inventory grid only**.
